# WHEN TO USE GraphRAG:

|                                             | Document Type | Chunk Size      | Overlap\* |
| ------------------------------------------- | ------------- | --------------- | --------- |
| Complex relationship queries                | General text  | 512–1024 tokens | 10–20%    |
| Multi-hop reasoning needed                  | Legal/medical | 256–512 tokens  | 20%       |
| Entity-centric questions                    |               |                 |           |

# Vector database – a database of embeddings

# SiT SINGAPORE INSTITUTE OF TECHNOLOGY

Vector DBs complement traditional DBs, they don't replace them.

# PIPELINE:

Most production systems use both.

Query → Graph Traversal → Connected Entities → LLM Answer

# WHEN TO USE GraphRAG:

| Feature                    | Traditional DB (SQL)         | NoSQL DB                                  | Vector Database                     |
| -------------------------- | ---------------------------- | ----------------------------------------- | ----------------------------------- |
| Multi-hop reasoning needed |                              |                                           | Sam Altman, Elon Musk               |
| Entity-centric questions   |                              |                                           |                                     |
| Data type                  | Rows, columns, text, numbers | Documents, key-value, graphs, wide-column | High-dimensional vectors + metadata |

# RAG evaluation - If you can’t measure it, you can’t improve it

# SiT SINGAPORE INSTITUTE OF TECHNOLOGY

| Metric              | What It Measures                  | Formula/Method                        | Good Score |
| ------------------- | --------------------------------- | ------------------------------------- | ---------- |
| Context Precision   | Are retrieved docs relevant?      | Relevant retrieved / Total retrieved  | > 0.8      |
| Context Recall      | Did we find all relevant info?    | Relevant retrieved / All relevant     | > 0.9      |
| Faithfulness        | Is answer grounded in context?    | LLM checks each claim against context | > 0.9      |
| Answer Relevancy    | Does answer address the question? | Cosine sim(question, answer)          | > 0.85     |
| VAnswer Correctness | Is the answer factually correct?  | Compare to ground truth               | > 0.8      |
| RAGAS Score         | Combined evaluation               | Harmonic mean of above metrics        | > 0.85     |

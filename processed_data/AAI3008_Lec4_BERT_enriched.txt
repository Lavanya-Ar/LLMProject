# Task - Masked LM

We simply mask some percentage of the input tokens at random, and then predict those masked tokens.

- Analogy: CBOW?
- masked LM (MLM)
- although it is often referred to as a Cloze task in the literature (Taylor, 1953).

The final hidden vectors corresponding to the mask tokens are fed into an output softmax over the vocabulary, as in a standard LM.

In all of our experiments, we mask 15% of all WordPiece tokens in each sequence at random.

We only predict the masked words rather than reconstructing the entire input.

Wilson L Taylor. 1953. Cloze procedure: A new tool for measuring readability. Journalism Bulletin, 30(4):415–433.

# Causal Language Modelling

# Definition

Causal Language Modeling predicts the next word in a sequence based on all previous words.

# Key Features

- Unidirectional: Looks only at the past, not the future.
- Autoregressive: Generates text one token at a time.

# Examples

- "The cat sat on the ___"
- Predicts "mat" based on the previous words.

# Parameter Count is Calculated in GPT

- The parameter count in GPT is mainly determined by the number of learnable weights 𝑊𝑊 and biases in the model.
- In practice, almost all parameters come from large weight matrices used in embeddings, self-attention, and feed-forward layers.
- Bias terms exist, but their contribution to the total parameter count is relatively small and often negligible compared to weights.

# KV Cache

- To store intermediate attention states during inference.
- In self-attention, each token produces Key (K) and Value (V) vectors.
- During generation, previously computed K/V do not change.
- KV cache stores them so we do not recompute past attention states.
- Do not recompute what has already been computed.

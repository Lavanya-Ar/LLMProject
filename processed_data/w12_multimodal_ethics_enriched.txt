# Vision Transformer (ViT)

# SiT SINGAPORE INSTITUTE OF TECHNOLOGY

1. Split an image into patches
2. Flatten the patches
3. Produce lower-dimensional linear embeddings from the flattened patches
4. Add positional embeddings
5. Feed the sequence as an input to a standard LLM transformer encoder
6. Pretrain the model with image labels (fully supervised on a huge dataset)

| Generator                                                                                                            | Encoder | Connector | Pre-trained |
| -------------------------------------------------------------------------------------------------------------------- | ------- | --------- | ----------- |
| A pre-trained modality encoder (e.g., CLIP-ViT for images, Whisper for speech) converts the modality into embeddings |         |           |             |
| A connector/projector (e.g., MLP) maps those embeddings into the LLM's token space                                   |         |           |             |
| The LLM backbone (e.g., LLaMA, Vicuna) reasons over the combined tokens                                              |         |           |             |

# AnyGPT: Any Modality In, Any Modality Out

# SINGAPORE INSTITUTE OF TECHNOLOGY

All modalities (speech, text, image, music) are converted to discrete tokens using modality-specific tokenizers.

A single LLM backbone processes the interleaved token sequence.

# Key shift:

OpenAI o1/o3 brought chain-of-thought reasoning to vision tasks: solving geometry problems, interpreting scientific figures, reading charts with step-by-step logic

# Data requirements:

| Challenge                                                               | Example                                  | Current Status (2026)               | Mitigation                               |   |
| ----------------------------------------------------------------------- | ---------------------------------------- | ----------------------------------- | ---------------------------------------- | - |

|                                                                         | (no cat)                                 | Being addressed with accessibility. | Noisy web scraped image text pairs       |   |

# Computational cost:

Training and running MLLMs require significant resources, limiting CLIP score filtering, GPT-4 data generation.

# Alignment across modalities:

Ensuring text, images, audio and other data are connected is technically complex.

Training Gemini requires thousands of TPUs, still meaningfully very expensive.

# Interpretability:

"Is the cup LEFT or RIGHT of the plate?" Weak for most models. Hard to understand why an MM-LLM makes certain decisions.

# Spatial Video reasoning:

"How many birds?" — unreliable beyond ~5. Still unsolved.

# Cross-modal alignment:

Visual and text features poorly aligned.

# Adversarial attacks:

Hidden text in images bypasses safety.

# Improving with better connectors:

Longer alignment pre-training.

# Active security concern:

Red-teaming, image-text consistency checks.

# Interpretability source:

Why did the model say X about the image? Largely unsolved. Attention visualization, probing.

# Better customization:

Usually text-only output.

# Attention is all you need

An Intuitive View of Attention (Learning / Project Context)

- Query: the current problem you are trying to solve
- e.g., a bug, a design decision, or a concept you are unsure about
- Key: concepts or semantic labels
- e.g., Tokenizer, RAG, Evaluation, Prompt Design
- used to identify which content might be relevant
- Value: the concrete content
- e.g., slides, example code, implementation details, explanations

What Attention Does:

- given a query, it finds the most relevant concepts (keys)
- and retrieves only the corresponding content (values)

Core Idea:

- you do not review everything every time
- you focus only on what is most relevant to the current problem

Vaswani A. Attention is all you need[J]. Advances in Neural Information Processing Systems, 2017. https://arxiv.org/pdf/1706.03762

# Residual Connections

- Motivation
- Deep models may forget previously learned information.
- As layers increase, useful signals can be weakened or distorted.
- Key Idea
- Residual connections allow information to flow directly across layers.
- Each layer learns a small refinement instead of a completely new representation.
- Formulation
- 𝐲 = 𝐹(𝐱) + 𝐱
- 𝐱 : input to the layer
- 𝐹(𝐱) : newly learned transformation
- Intuition
- If the new layer is not useful, the model can fall back to the original input.
- This helps prevent the model from forgetting earlier representations.

# Masked SIT Internal SiT

# Self-attention layers in the decoder

- We need to prevent leftward information flow in the decoder to preserve the auto-regressive property.
- For example, if you have only generated [𝑦𝑦1, 𝑦𝑦2], the model cannot access or "see" the values of [𝑦𝑦3, 𝑦𝑦4].
- Mask out (setting to −∞) all values in the input of the softmax which correspond to illegal connections.

# Formula (with mask M):

Attention(Q, K, V) = Softmax( (QKT + M) / √dk) V

M is the triangular mask ensuring causal behavior.

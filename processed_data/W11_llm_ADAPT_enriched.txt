# How QLoRA Quantizes: Absmax Quantization

# Goal:

Represent 32-bit float weights using only 4 bits, with minimal precision loss.

1. Step 1 — Scale: Find the max absolute value → use it to scale all values to [-1, 1]
2. Step 2 — Map: Divide [-1, 1] into 16 equal buckets (since 4 bits = 24 = 16 values)
3. Step 3 — Assign: Round each value to the nearest bucket center → store as 4-bit code
4. Step 4 — Dequantize: To compute, multiply 4-bit code × scaling factor back to approximate float

# Module and Teaching Feedback AY25/26, Tri 2

Memory savings: 32-bit → 4-bit = 8× compression.

Limitations of Supervised Learning for LLMs
SiT SINGAPORE
INSTITUTE OF TECHNOLOGY

# Why training on labeled data alone is not enough for modern language models?

# 01 Label Quality Ceiling

Model performance is bounded by annotator quality. Human labelers make mistakes, disagree on edge cases, and introduce biases — the model can never exceed its training signal.

# 02 No Notion of Preference

Supervised learning optimizes for predicting a fixed label, not for generating responses humans actually prefer. It cannot distinguish a good answer from a technically correct but unhelpful one.

# 03 Cannot Learn from Feedback

SL has no mechanism to incorporate post-deployment signals. The model cannot improve from user corrections, ratings, or behavioral feedback without full retraining.

# 04 Objective Misalignment

Minimizing cross-entropy loss does not equal being helpful, honest, or safe. SL rewards the most likely next token — not the most useful or aligned response.

# Group Relative Policy Optimization (GRPO)

# SiT SINGAPORE INSTITUTE OF TECHNOLOGY

- Used in Deepseek
- PPO needs a value model to estimate "how good is this state?"
- GRPO computes this baseline empirically from the group of responses
- Result: 3 models instead of 4; more stable training

1. Complete both module and teaching feedback.
2. Please share constructive feedback in the free text sections.
3. Academic Staff will not be able to identify the student. All their grades will not be affected as the feedback results will only be shared with the academic staff after the release of exam results.

# How GRPO works:

1. For each prompt, generate G responses
2. Score each response with a reward model
3. Compute advantage for each response: Aᵢ = (rᵢ - mean(r)) / std(r)
4. Update model to increase probability of high-advantage responses

DeepSeek-R1 achieved GPT-4-level reasoning using GRPO

# Quantization: model compression

# SiT SINGAPORE INSTITUTE OF TECHNOLOGY

# Quantization: reducing the precision of numerical values.

# Post-Training Quantization (PTQ)

Start with a pre-trained model and evaluate it on a calibration dataset.

Calibration data is used to calibrate the model. It can be a subset of training data.

Calculate dynamic ranges of weights and activations in the network to compute quantization parameters (q-params).

Quantize the network using q-params and run inference.

# Quantization-Aware Training (QAT)

Start with a pre-trained model and introduce quantization ops at various layers.

Finetune it for a small number of epochs.

| A 7B model | in FP32: 28GB | in INT4: 3.5GB |
| ---------- | ------------- | -------------- |

Simulates the quantization process that occurs during inference.

The goal is to learn the q-params which can help to reduce the accuracy drop between the quantized model and pre-trained model.

# How to Choose the Right Strategy

# SiT SINGAPORE INSTITUTE OF TECHNOLOGY

| Your Situation                         | Recommended Approach                                                                                                                                                   |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Need external/live knowledge           | RAG (+ optionally fine-tune for style)                                                                                                                                 |
| Need consistent tone/style/brand voice | SFT (Instruction Tuning)                                                                                                                                               |
| Need new skill (math reasoning, code)  | SFT + GRPO with verifiable rewards                                                                                                                                     |
| Need safety/helpfulness alignment      | SFT + DPO or ORPO Academic Staff will not be able to identify the student. All feedback received are anonymous.                                                        |
| Limited GPU (single consumer card)     | QLoRA (4-bit) + LoRA adapters Their grades will not be affected as the feedback results will only be shared with the academic staff after the release of exam results. |
| Very limited data (<1K examples)       | Prompt engineering + few-shot, or DPO                                                                                                                                  |
| Need a smaller deployable model        | Knowledge Distillation or Quantization                                                                                                                                 |
| Large team, production deployment      | SFT → DPO/ORPO → Quantize → Deploy                                                                                                                                     |

In practice: Prompt Engineering → RAG → SFT (LoRA/QLoRA) → Alignment (DPO/ORPO) → Quantization. Each step adds cost and complexity — stop when you've solved the problem.

# Algorithm 1 Learn BPE operations

1. Split word into characters, form a vocabulary
- low → l o w
- ‘l o w ’ : 5

Count the frequency of each bigram, get pair statistics
- Tow characters:
- ‘l o’ : 7; ‘o w’ : 7

- A sub-word and a character: lo w
2. Merge the most frequently appeared bigram
- l o → lo
- ‘lo w ’ : 5
3. Repeat 2 and 3 until some threshold is met
- Number of merges
- Vocabulary size

# Continuous Bag of Words (CBOW)

- Project one-hot vector to a dense, low-dimensional embedding space.
- 𝑊 is a 𝑉 ∗ 𝑁 matrix
- 𝑉 is the vocabulary size
- 𝑁 is the embedding dimension (e.g., 100 or 300).
- Embedding vector for a word 𝑥𝑖
- ℎ𝑖 = 𝑊T𝑥𝑖
- Averaging Embeddings
- ℎ = 1/𝐶 ∑𝑖=1𝐶 ℎ𝑖
- 𝐶 is the number of context words.
- Output word 𝑜 = 𝑊Tℎ
- Size of 𝑊 is 𝑁 ∗ 𝑉
- 𝑜 is a vector of size 𝑉

Softmax Function P𝑤𝑡 = ∑𝑗=1𝑉 𝑒𝑐𝑗

The model predicts the word with the highest probability.

# Discussion

- One input, multiple true output
- The training target is to get the vectors
- Not the one-to-one mapping
- Reduce the computational complexity
- Negative Sampling*
- Focuses on a small subset of "negative" samples instead of the full vocabulary
- Hierarchical Softmax*
- Reduces computational complexity by structuring the vocabulary as a binary tree
- Huffman Tree*
- Huffman tree is built by repeatedly merging the two least frequent nodes.
- Assign shorter paths to more frequent words, making training even more efficient.

Mikolov T, Sutskever I, Chen K, et al. Distributed representations of words and phrases and their compositionality[J]. Advances in neural information processing systems, 2013, 26.
